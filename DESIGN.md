# Anime × IT profile

The profile is a small visual story: a night-time Seoul studio, a character file,
four project missions, a toolkit and a public activity signal. All identity,
education, employment and project facts come from the previous profile README.
Project covers are editorial vector illustrations, rather than app screenshots.

## Maintenance

```sh
python scripts/profile_art.py       # Rebuild the 11 small SVG illustrations
python scripts/build.py             # Fetch public GitHub data and rebuild activity
python scripts/build.py --offline   # Rebuild from the last successful snapshot
python scripts/build.py --static    # Disable decorative motion in the dashboard
python scripts/snake.py assets      # Rebuild the decorative DESIGNER snake
```

The daily workflow only stages `dashboard.svg` and `activity.json`. It cannot
overwrite the anime cover or the project illustrations. A failed network request
or an unrecognized contribution calendar leaves the previous data intact.
Language percentages use all public non-fork repository language bytes; the top
five are shown and the remainder is stated separately. Streaks use Asia/Seoul.

The README uses local images, normal links, real text and native details/picture
elements. It requires no custom GitHub CSS, JavaScript, external badge generator
or profile statistics service. Decorative SVG motion respects reduced-motion
preferences; the longer snake animation is behind an optional details element.
Image alt text preserves the meaning when graphics cannot be loaded.
